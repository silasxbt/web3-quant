# 变更日志

## 0.1.0 - 2026-06-08

初始版本。

### 已实现

- Rust workspace 与本地运行配置
- Binance / OKX 永续合约公共行情扫描
- U 本位永续与币本位永续共同币种自动发现
- 黑名单机制
- spread 计算与可疑超大价差过滤
- 最小净 spread 报警阈值 4%
- 最大滑点估算 0.5%
- 默认建议仓位 100 USDT
- 偏谨慎盘口深度降档
- funding 风险提示框架
- 交互式 Telegram Bot 推送与按钮回调
- macOS 系统通知
- 本地 Web 控制台
- 闪电审计：OpenAI 兼容模型审计 Agent
- 全局中文显示配置
- 每个功能模块的中文说明
- 本地 `.command` 启动链路
- macOS LaunchAgent 手动托管服务
- 测试盘/生产盘配置字段

### 闪电审计

- 支持 OpenAI 兼容 `/v1/chat/completions`
- 支持 OpenAI 兼容 `/v1/models` 模型刷新
- 支持模型选择、提示词选择和提示词编辑
- 支持本地保存审计配置到 `data/lightning-audit-config.json`
- 支持在活跃机会中手动触发审计
- 审计结果展示机会快照、检索入口、模型输入、模型返回和可见依据

### 尚未实现

- Binance/OKX 签名交易客户端
- 测试盘真实下单/撤单/仓位对账
- 双边自动开仓和平仓执行器
- 单边成交补偿逻辑
- 生产盘小额自动灰度

### 风险说明

当前版本仍以行情监控和提醒为主，不提供生产盘真实交易能力。详见 `DISCLAIMER.md`。
